# Home Master Services

โปรเจคเว็บไซต์นำเสนองานบริการดูแลและซ่อมแซมบ้าน (Home Improvement Services) ที่ออกแบบมาให้ดูทันสมัยและใช้งานง่าย 

**จุดเด่นของโปรเจค:**
- หน้าเว็บแสดงรายละเอียดบริการต่างๆ อย่างชัดเจน เช่น การซ่อมแซม, การปรับปรุงบ้าน, และการรับประกันผลงาน
- ดีไซน์สวยงาม มีลูกเล่นแอนิเมชันตอนเลื่อนหน้าเว็บ (Scroll Animations)
- รองรับการแสดงผลทุกหน้าจอ (Responsive Design) ใช้งานได้ดีทั้งบนมือถือและคอมพิวเตอร์

---

## English Description

A modern and user-friendly landing page website designed for Home Improvement and Maintenance Services.

**Key Features:**
- Clear presentation of various services, including home repairs, renovations, and service guarantees.
- Beautifully designed with smooth scroll animations.
- Fully responsive design, providing a seamless experience on both mobile devices and desktop computers.
